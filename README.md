# backend

청년 지원 AI 비서 조이의 백엔드 및 AI 에이전트 저장소입니다.

## 기술 스택

2026-11-18 결정 기준입니다.

| 구분 | 언어 | 프레임워크·도구 |
| --- | --- | --- |
| 프론트엔드 | TypeScript | React + Vite |
| 백엔드 API | Python | FastAPI |
| 조이 AI 에이전트 | Python | 백엔드 저장소 내부에서 함께 개발 |

프론트엔드는 [youth-ai-agent/frontend](https://github.com/youth-ai-agent/frontend)에서 관리합니다. AI 모델·에이전트 라이브러리·DB·인증 방식·전화 연동 서비스는 아직 미정입니다.

## 요구사항

[백엔드 및 AI 비서 요구사항](docs/requirements.md)

- 회원가입·첫 이용 시 선택형 현재 상태 체크
- 짧은 말과 선택지로 진행하는 조이 대화
- 정책·프로그램 탐색과 조건 확인
- 전화 문의 대행, 신청 준비, 일정·참여 이력 관리

## 현재 상태

요구사항과 기술 스택을 정리한 단계입니다. 실행 코드와 설치·실행 명령은 구현 후 추가합니다.
