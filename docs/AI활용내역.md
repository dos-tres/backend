# AI 활용내역

**① 활용 AI 모델·도구**
- [서비스] OpenAI GPT-4.1 mini API: 대화 이해(상태·관심 분야·요청 정리, 검색어 변환), 선택한 공고에 대한 질문 답변, 청년센터 공고 정보 추출·지원 영역 분류, 신청 문항 초안 작성
- [개발] Claude Code(Claude Opus 5.5): 백엔드 코드 초안·리팩터링·디버깅, 테스트 작성 [팀 확인: Codex 등 그 밖의 개발 도구]
- [문서] Claude: 프로젝트 소개서·AI 활용내역 문장 다듬기, 문서 내용과 실제 구현 대조
- [디자인] [팀 확인: 조이 캐릭터 이미지 생성 도구] (AI 생성 이미지)

**② AI 활용 범위와 팀의 기여**
- 서비스 기능: AI는 사용자의 자유 입력을 상태·관심 분야·요청·검색어로 구조화하고, 공고 원문을 근거로 질문에 답하며, 신청 문항 초안을 작성함. 자격 판단과 추천 순서·추천 이유는 AI를 쓰지 않고 팀이 설계한 규칙으로 계산함(연령·거주지·취업 상태·학력·마감 여부 비교, 상태 체크·관심 분야·거주 지역 기반 점수). 같은 입력이면 항상 같은 결과가 나오며, 결과 개수·이름이 들어가는 안내 문장도 서버가 실제 결과로 만듦.
- 데이터: 온통청년 API 수집, 청년센터 게시판 크롤러, 매일 갱신하는 파이프라인은 팀이 설계함. AI는 형식이 제각각인 공고 본문에서 대상·일정·장소·신청 기간·준비물을 추출하고, 정책과 같은 기준으로 지원 영역을 분류함.
- 개발: 코드 초안과 리팩터링은 AI가 생성하고, 팀이 요구사항·API 계약·DB 구조를 정한 뒤 코드를 검토·수정·통합함. 문제 정의, 상태 체크 문항, 추천 가중치, 프롬프트(말투·금지 규칙)는 팀이 설계하고 점검 결과에 따라 고침.

**③ API·외부 데이터·오픈소스**
- API: 온통청년 청년정책 API(정책 수집), OpenAI API(서비스 AI), 카카오맵 API(센터 위치), Google Forms(시연용 신청서)
- 외부 데이터: 서울청년센터 오랑 및 지역 청년센터 게시판 공고(프로그램 수집), 법정동코드(지역 선택, 2026-11-20 기준)
- 오픈소스: FastAPI, SQLAlchemy, Alembic, uvicorn, requests, BeautifulSoup, psycopg, pydantic-settings(백엔드), React, Vite, TypeScript, lucide-react(프론트엔드)
- 상세 출처·링크·라이선스는 소개서 지정 별첨의 「활용한 외부 자원·출처」 표에 기재함.

**④ 검증 및 한계 대응**
- 코드 검증: 자동 테스트 148개로 추천 규칙·자격 판단·API·DB 적재를 검증함. 대화 평가 시나리오 84건으로 요청 파악, 질문 반복, 결과 안내를 점검하고 프롬프트와 후처리 규칙을 고침.
- 공고 추출 검증: AI가 뽑은 항목마다 원문 근거 구절을 함께 받아, 근거가 실제 본문에 있을 때만 저장함(프로그램 137개 중 127개 통과, 나머지는 수집한 원문 정보로 표시).
- 환각 방지: 서버가 조건으로 거른 데이터 안에서만 답하게 하고, 정책 이름·소득·자격을 지어내지 않도록 프롬프트에서 금지함. 데이터로 확인되지 않은 조건은 "추가 확인이 필요해요"로 안내하고, 모든 추천에 공식 공고 링크를 표시함.
- 안전: 자살·자해 표현은 AI 판단에 맡기지 않고 규칙으로 감지해 109 등 상담 연락처를 먼저 안내함. 화면에 AI가 답변한다는 사실을 표시함.
- 개인정보: 로그인 없이 이용하며 설문·대화는 서버에 저장하지 않음. 추천 조건으로는 나이·지역·취업 상태·학력만 AI에 전달하고, 신청 초안 작성 시 이름·연락처는 [이름]처럼 바꿔 보냄. 시연·영상에는 가상 데이터만 사용함.
- 남은 한계: 소득 조건은 판정하지 않고 확인 필요로 표시함. 청년센터 프로그램은 서울 중심으로 수집됨. 신청 대행은 시연용 신청서에만 연결됨. 대화 자유 입력의 개인정보 마스킹은 향후 적용 예정임.
