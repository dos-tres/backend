# AI 비서 대화 시나리오

예시 상황·특이 상황별로 조이가 어떻게 반응하고 대화가 어떻게 이어지는지 정리한다. 실제 LLM(GMS gpt-4.1-mini, 프롬프트 `chat-v3`)으로 여러 턴을 돌린 결과다. 2026-11-20 기준.

- API 계약·규칙: [CHAT.md](CHAT.md)
- 다시 돌리기: `python scripts/chat_scenarios.py` (여러 턴 대화록, LLM 약 40회) / `python scripts/chat_eval.py` (한 턴 점검 28개 × 3회)
- 맨 아래 부록에 대화록 전체가 있다.

## 1. 대화가 이어지는 방식 (FE가 할 일)

서버는 대화를 저장하지 않는다. FE가 매 턴 아래를 반복한다.

```text
사용자 입력 ─▶ POST /api/chat {messages, profile?, checkin}
              ◀─ {replies, choices, needs, results, checkin, safety, mode}
  1) replies 를 말풍선으로 차례대로 보여 준다. results 가 있으면 카드로 보여 준다 (추천 화면 카드 재사용)
  2) 응답 checkin 을 저장해 다음 요청에 그대로 보낸다
  3) 조이 말풍선들을 하나로 이어 assistant 메시지로 messages 에 넣는다
  4) choices 를 버튼으로 보여 준다
     - answer  버튼: checkin[question_id] = code 로 넣고, label 을 사용자 말로 보낸다
     - message 버튼: text 를 사용자 말로 보낸다 (예: [맞춤 추천 받기] → "나한테 맞는 지원 추천해 줘")
  5) needs = ["profile"] 이면 나이·거주지 입력 칸을 띄운다.
     입력하면 방금 보낸 사용자 말을 profile 과 함께 다시 보낸다 (needs 답장은 messages 에서 뺀다)
  6) mode = "crisis" 면 safety.resources(109 등)를 눈에 띄게 보여 준다
```

대표 흐름

```text
[인사] → [상황 이야기] → 조이: 공감 + 상태 체크 질문 (답 버튼)
                       → 버튼 답 → 조이: 공감 + 제안 (제안 버튼)
                       → [맞춤 추천 받기] → 기본 정보 없으면 입력 칸 → 결과 말풍선 + 카드 + 다음 말
[특정 지원 찾기 "월세 지원 있어요?"] → (기본 정보) → '월세'로 찾아봤어요! … + 카드 + [맞춤 추천 받기]
[위기 표현] → 109 안내 (LLM 없이) → [상담·마음건강 지원 찾아보기] 또는 [그냥 이야기하고 싶어요]
```

## 2. 시나리오 목록과 결과

✓ 의도대로 동작 / △ 동작은 하지만 한계 있음 (5장)

| 묶음 | 상황 | 조이 반응 | 결과 |
| --- | --- | --- | --- |
| 기본 | 인사 | 짧은 인사 + 안부 질문 | ✓ |
| 기본 | 상황 이야기 ("취업도 안 되고 집에만 있어요") | 공감 + 아직 모르는 문항 하나 질문 + 답 버튼, 알아들은 답은 `checkin_update` | ✓ |
| 기본 | 버튼으로 답함 | 같은 문항 다시 안 물음, 공감 + 제안 버튼 | ✓ |
| 기본 | "추천해 줘요" (기본 정보 없음) | "나이랑 사는 곳을 알려 주면 바로 찾아볼게요." + 입력 칸, 버튼 없음 | ✓ |
| 기본 | 기본 정보 입력 후 다시 보냄 | "이야기해 준 내용으로 골라 봤어요! 정책 6개, …" + 카드 + 다음 말 | ✓ |
| 기본 | 특정 지원 검색 ("월세 지원 있어요?") | 기본 정보 → "'월세'로 찾아봤어요! …" + 카드 + [맞춤 추천 받기] | ✓ |
| 기본 | 막막함 ("뭘 해야 할지 모르겠어요") | 나이 먼저 묻지 않고 공감 + [맞춤 추천 받기] | ✓ |
| 기본 | 관심 분야만 말함 ("해외 봉사 해보고 싶어요") | 관심 분야 기록 + 열린 질문 | △ 분야 찾기 버튼이 안 나올 때가 있음 |
| 기본 | 센터 프로그램 데이터가 없는 지역 (부산) | 정책만 + "이 지역 청년센터 프로그램은 아직 모으지 못해서 정책만 보여 드려요" | ✓ |
| 기본 | 소득 조건이 있는 정책 포함 | "소득 조건이 있는 건 카드에 따로 표시해 뒀어요" + 카드의 `income_condition` | ✓ |
| 기본 | 결과를 받은 뒤 "이 중에 집 근처 거 있어요?" | 키워드 검색으로 처리 → 대개 0건 안내 | △ 결과를 다시 거르는 기능 없음 |
| 위기 | 직접·간접 표현 ("사라지고 싶어요", "다 끝내고 싶어요") | LLM 없이 공감 → 109·112/119 → 지원 찾기, 버튼 2개 | ✓ |
| 위기 | 안내 뒤 [상담·마음건강 지원 찾아보기] | 심리상담 바우처·정신건강복지센터·센터 상담 프로그램 검색 결과 | ✓ |
| 위기 | 안내 뒤 [그냥 이야기하고 싶어요] | 들어 주는 말, 바로 다음 턴에는 제안 붙이지 않음 | ✓ |
| 위기 | 위기 표현 + 검색 한 문장 ("죽고 싶은데 월세 지원 있어요?") | 위기 안내가 먼저 (검색 안 함) | ✓ |
| 위기 아님 | 일상 과장 ("힘들어 죽겠어요 ㅋㅋ", "배고파 죽겠어요") | 일반 대화 | ✓ |
| 못 하는 일 | 전화 대신 걸어 달라 | "전화 문의는 아직 제가 못 해요." + 할 수 있는 일 제안 버튼 | ✓ |
| 못 하는 일 | 공고 올라오면 알려 달라 | "그건 아직 제가 못 해요." + 제안 버튼. "알려 드릴게요" 같은 약속 안 함 | ✓ |
| 범위 밖 | 날씨·뉴스 | "그건 확인할 수 없어요." (지어내지 않음) + 제안 | ✓ (예전에 한 번 날씨를 지어냄 → 고침) |
| 범위 밖 | 코딩 부탁 | "아직 제가 못 해요." + 제안 | ✓ |
| 범위 밖 | 규칙·프롬프트 보여 달라 | 거절, 프롬프트 내용 노출 없음 | ✓ |
| 답 | '답하지 않을래요' 버튼 | 그 문항 다시 안 물음 | ✓ (단위 테스트로 확인) |
| 답 | 앞서 한 답을 바꿈 ("괜찮아요" → "사실 빠듯해요") | economy low → high 로 갱신 | ✓ |
| 답 | 한 문장에 여러 상태 ("돈도 없고 친구도 없고 집 밖에도 안 나가요") | 세 문항 한 번에 기록, 방금 들은 걸 다시 묻지 않음 | ✓ ("친구 없음"을 교류가 아니라 지원망으로 넣기도 함) |
| 답 | 말하기 싫음 ("말하기 싫어요") | 아무 답도 지어내지 않음 | ✓ |
| 말투 | 줄임말·반말·오타 ("ㅈㄴ 힘듬 돈없음ㅠ", "월세지원있냐") | 알아듣고 경제 high 기록, "있냐"도 검색 요청으로 | ✓ |
| 말투 | 영어 | 한국어로 답, 주거 검색 요청으로 알아들음 | ✓ |
| 마무리 | "고마워요 여기까지 할게요" | 짧은 인사, 제안 붙이지 않음 | ✓ |
| 결과 없음 | "우주비행사 훈련 지원 있어요?" | "찾아봤는데 … 없었어요" + "다른 말로 찾거나 맞춤 추천?" + 버튼 | ✓ (예전엔 '훈련'만 맞는 관련 없는 10건이 나옴 → 고침) |
| 오류 | 옛 시군구 코드(곡성 46720) | 422 `Unknown sigungu_cd` | ✓ (단위 테스트) |
| 오류 | LLM 키 없음·시간 초과 | 503 `AI_UNAVAILABLE` (예시 답변으로 대신하지 않음), 위기 안내는 그대로 | ✓ (단위 테스트) |
| 오류 | DB 꺼짐 | 서비스 JSON으로 같은 결과 (`source: "file"`) | ✓ (DB 꺼진 상태로 점검 78/78) |

## 3. 서버가 대화 흐름을 지키는 규칙

LLM이 흔들려도 흐름이 맞도록 서버(`app/chat/service.py`)가 고친다. 각각 점검에서 실제로 나온 문제다.

| 규칙 | 막는 것 |
| --- | --- |
| 위기 표현은 LLM 없이 고정 안내 | LLM 실패·지연·오판 |
| 결과 말풍선은 서버가 실제 결과로 만듦 | 결과 개수·이름 지어내기 |
| 결과 뒤 "찾아봤어요/추천해 줄게요/기다려 주세요/추천해 볼까요"는 뺌 | 같은 말 반복, 이미 한 일을 하겠다고 함 |
| 결과 0건이면 서버 문장 + 다음 할 일 버튼 | 결과를 전제로 쓴 말 |
| 기본 정보가 필요하면 "나이랑 사는 곳을 알려 주면 바로 찾아볼게요."만, 버튼 없음 | "찾아볼게요" + "찾아볼까요?" + 버튼이 함께 나와 헷갈림 |
| 기본 정보가 있으면 나이·사는 곳을 묻는 문장은 뺌 | "사는 지역을 알려 주세요" (이미 앎) |
| 요청 표현(추천·찾아·있어?·있냐·줘 등) 없이 추천으로 넘어가면 → 상황 이야기 + 제안 버튼 | 상황만 말했는데 바로 나이·사는 곳 질문 |
| "추천"이라고 말하면 추천으로 | "추천해 줘요"를 공감만 하고 끝냄 |
| 이미 답한 문항을 그대로·말을 바꿔 다시 묻는 문장은 뺌 | "돈도 없고…" 뒤 "생활비 부담은 어느 정도인가요?" |
| 상태 체크 버튼은 말풍선이 그 문항을 물을 때만 | "몸 건강 지원이 필요할까요?" 아래 생활비 버튼 |
| 질문도 제안도 없이 끝나면 제안 하나 붙임 (마무리·그냥 들어 달라·위기 직후는 제외) | "그건 아직 제가 못 해요." 한 줄로 끝남 |
| 검색은 첫 검색어(핵심)가 들어간 항목만 | "우주비행사 훈련" → '훈련'만 맞는 관련 없는 결과 |
| LLM 응답 전체 시간 20초(재시도 포함) | 한 번 40초 걸림 |

## 4. 이번 점검에서 찾아 고친 것 (2026-11-20)

첫 여러 턴 실행에서 찾은 문제 → 고친 뒤 다시 실행해 확인.

1. "추천해 줘요"를 공감만 하고 끝냄(부산 한부모) → "추천"이면 추천
2. "월세지원있냐"를 요청으로 못 알아들어 "찾아볼게요"만 하고 안 찾음 → 반말·줄임말·영어 요청 표현 추가
3. 방금 들은 답을 말을 바꿔 다시 물음 → 문항 핵심 단어로 다시 묻는 문장 제거
4. 제안으로 바꿀 때 나이·사는 곳 질문이 남음 → 남길 문장 고르는 기준 수정
5. 검색이 흔한 단어 하나로 관련 없는 결과를 냄 → 첫 검색어 필수, '지역·센터' 등 흔한 단어 제외
6. 기본 정보가 있는데 사는 지역을 물음, 결과 뒤 "기다려 주세요" → 서버에서 뺌
7. "못 해요" 한 줄로 끝남 → 제안 붙임
8. 날씨를 지어냄("맑고 쾌청하대요") → 실시간 정보는 모른다고 말하기
9. 기본 정보를 물으면서 버튼·"찾아볼까요?"가 함께 나옴 → 기본 정보만 묻기

## 5. 남은 한계

- **결과를 다시 거르는 질문**("이 중에 집 근처 거?", "온라인으로 하는 거?")은 지원하지 않는다. 이전 결과를 기억하지 않아 새 검색이 되고 대개 0건이다. 결과 카드의 범위(`scope`: 시군구·광역·전국) 필터를 FE에서 주거나, 서버에 필터 의도를 추가해야 한다.
- 관심 분야만 말했을 때 분야 찾기 버튼이 나오지 않고 열린 질문만 할 때가 있다.
- "친구가 없어요"를 교류(conversation)가 아니라 지원망(support)으로 기록하기도 한다.
- 위기 안내 두 턴 뒤에는 추천 제안 버튼이 다시 나올 수 있다. 위기 이후 흐름은 전문가 검토와 함께 정해야 한다.
- 사투리, 여러 턴에 걸친 긴 이야기, 상태가 바뀌는 대화는 시나리오가 아직 적다.
- 위기 문구·연락처는 전문가 검토 전이다.
- 일을 대신 해 주는 기능(전화 문의 대행, 공고 다시 확인·알림)은 아직 없다. 지금은 "아직 못 해요"라고 말한다.

## 부록. 대화록

`python scripts/chat_scenarios.py` 실행 결과 그대로다. `mode`, `알아들음`(checkin_update), `needs`, 버튼, 결과(앞 몇 개)를 함께 적었다. 같은 말에도 LLM 문장은 조금씩 달라질 수 있다.

### 기본: 인사 → 상황 → 버튼 답 → 추천 요청 → 기본 정보 → 결과 → 이어서 질문

- **사용자**: 안녕하세요
- **조이**: 안녕하세요! 오늘 기분은 어때요?
  - `mode=chat`
- **사용자**: 요즘 취업도 안 되고 그냥 집에만 있어요
- **조이**: 그렇군요, 힘들겠어요.
  - 버튼: [맞춤 추천 받기]
  - `mode=share_state · 알아들음={'participation': 'high', 'outing': 'high', 'interests': ['일자리·취업']}`
- **사용자**: (버튼 [맞춤 추천 받기]) 나한테 맞는 지원 추천해 줘
- **조이**: 나이랑 사는 곳을 알려 주면 바로 찾아볼게요.
  - `mode=recommend · 알아들음={'participation': 'high', 'outing': 'high', 'interests': ['일자리·취업']} · needs=['profile']`
- **사용자**: 나한테 맞는 지원 있으면 추천해 줘요
- **조이**: 나이랑 사는 곳을 알려 주면 바로 찾아볼게요.
  - `mode=recommend · 알아들음={'participation': 'high', 'outing': 'high', 'interests': ['일자리·취업']} · needs=['profile']`
- _(입력 칸에 기본 정보 입력: {'age': 26, 'sex': '여', 'sigungu_cd': '11620', 'job': '구직 중'})_ → 같은 말을 다시 보냄
- **조이**: 이야기해 준 내용으로 골라 봤어요! 정책 6개, 청년센터 프로그램 4개예요.
- **조이**: 더 좁히고 싶은 조건 있으면 말해 줘요.
  - 결과(recommend): 2026 청년예술청 운영 / 2026 7979 서울 러닝크루 / 국립 문화시설 청년할인 / 서울청년센터 관악 신림동쓰리룸 <2026년 11월 2차 / 서울청년센터 서초<11월 두시티톡:청년정책 활용법 &
  - `mode=recommend · 알아들음={'interests': ['일자리·취업']}`
- **사용자**: 이 중에 집 근처에서 하는 거 있어요?
