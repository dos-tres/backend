# 공고 정보 추출과 취업 시연

2026-11-23 로컬 구현. 배포하지 않았다.

## 데이터 흐름

원문 전체 수집 → 메일 머리말·인사·서명·개인 연락처 정리 → AI 필드 추출 → 인용 근거 검증 → 내용 해시/추출 버전 캐시 → 서비스 데이터/공통 표시.

- 수집 본문의 4,000자 절단과 통합 요약 300자만을 분류에 사용하는 경로를 수정했다. `source_content`와 runtime 원문 파일에 전체 본문을 보존한다.
- 요약, 대상, 신청 방법, 신청 기간, 활동 일정, 개최 장소, 준비물을 구분한다. 각 인용 구절이 원문에 실제로 있는지 검사한다. 인용 일치가 의미적 정확성 전체를 증명하는 것은 아니므로 표본 검토와 문맥 검증을 병행한다.
- 운영 센터를 개최 장소로 추정하지 않는다. `제한없음` 근거가 없으면 누구나 신청 가능으로 넓히지 않는다.
- 신청/접수 맥락이 확인된 직접 폼 링크만 신청 URL로 사용한다. 지도·만족도 설문을 신청 링크로 취급하지 않는다.
- 원문, 캐시 파일, 테스트 폼 설정은 Git에 넣지 않는다. 검증된 사실과 근거는 서비스 seed의 `facts`에 포함해 재시작 후에도 사용할 수 있게 했다.
- API는 원문이나 추출 증거 전체를 노출하지 않는다. 목록/추천/상세/대화와 FE 오프라인 스냅샷은 같은 정리된 정보를 사용한다.
- 대화마다 공고 요약을 다시 생성하지 않는다. 개인화 이유는 실제 후보 선별 근거로 만든다.

## 실행

```sh
.venv/bin/python -m pipeline.programs.extract_facts --limit 5
.venv/bin/python -m pipeline.programs.extract_facts
.venv/bin/python -m pipeline.programs.extract_facts --no-llm
# 특정 항목만 재시도
.venv/bin/python -m pipeline.programs.extract_facts --only orang:75646
```

`--strict`는 한 항목이라도 실패하면 비정상 종료한다. 기본 모드는 일부 실패 시 이전 정상 결과를 유지하고 성공한 항목을 저장한다. 실패 이유는 runtime 캐시에 별도 기록한다. 원문이 없거나 근거를 검증하지 못한 결과를 정상 추출처럼 저장하지 않는다.

## 추천

프로그램 요청은 전체 지역 후보를 대상으로 자격 필터와 요구 근거를 비교하고 최대 3개를 반환한다. 직접 자소서/면접 피드백 요청에는 첨삭·피드백·모의면접 근거가 필요하다. 일반 문화 행사로 결과 수를 채우지 않는다. 활동 날짜가 지난 행사는 후보에서 제외한다. 새 정책 요청이 이전 문화/프로그램 맥락에 묶이지 않도록 했다.

대표 가상 사용자(23세/강동구/구직 중)의 요청에서는 중구 1:1 진로 전문가 상담 1개가 남았다. 이력서 첨삭, 면접 준비, 직무 탐색 내용과 장소·일정을 원문에서 확인했다. 접수와 상담시간 확정은 구분한다.

## 신청·개인정보

- 현재 FE start 요청은 `item_id`만 보낸다. 이름/연락처/생일/동 단위 거주지·나이는 FE에서 채운다. 동의는 자동 선택하지 않는다.
- 긴 답변 초안은 사용자가 입력한 참여 이유만 사용한다. 저장 정보와 신청서에서 새로 입력한 이름/연락처 등을 FE에서 치환한 뒤, 서버가 구성한 AI 입력을 미리 보여준다. 현재 FE는 다른 신청 답변 전체를 draft 요청에 보내지 않는다.
- 최종 제출 순간에는 답변 전체가 BE를 거쳐 Google Forms로 전달된다. 서버는 이 값을 저장/로그하지 않는다. BE가 개인정보를 절대 받지 않는 구조는 아니다.
- 폼 문항·동의 내용의 해시가 바뀌면 현재 FE의 제출을 중단하고 다시 확인하게 한다. 이전 클라이언트를 위한 선택적 revision 호환 경로는 남겨 두었다.
- 서버 성공 확인 전에 완료를 표시하지 않는다. 결과 불명확 시 자동 재제출하지 않는다.

## 테스트 폼과 실제 공고 구분

사용자가 제공한 열린 폼은 **[둘셋 테스트] 베이킹 클래스**다. 취업 프로그램 신청서로 가장하지 않는다. 로컬 Git 제외 설정에 별도 `demo:open`, `demo:closed` 항목으로 연결했다. 편집 링크는 사용하지 않았다. 실제 제출은 수행하지 않았다.

실제 공고 대화 → 신청 준비/공식 경로 안내를 보여주고, 별도 장면에서 팀 소유 테스트 폼의 자동 채움·참여 동기·최종 확인을 시연한다. 취업 프로그램의 실제 폼 연결이 필요하면 해당 기관의 허용된 테스트 경로를 별도로 준비해야 한다.
